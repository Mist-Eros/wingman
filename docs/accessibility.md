# Accesibilitate — Wingman

Wingman trebuie să poată fi folosit de angajați cu dizabilități. Setările sunt
globale (sesiune) și se aplică imediat în login, reporter, dispecer, echipaj și
cont: `Accesibilitate` din login sau din cont.

## Profiluri implementate

| Profil | Ce activează |
|---|---|
| **Orb / vedere redusă** | text 135%, contrast ridicat, ghidaj vocal, ținte mari |
| **Mut / fără voce** | mod tastare prioritar, alerte vizuale, text 115%, ținte mari |
| **Surd / hipoacuzic** | alerte vizuale + vibrație, contrast ridicat, text 115% |
| **Daltonist** | paletă sigură (nu doar roșu/verde), contrast ridicat |
| **Mobilitate redusă** | ținte de atingere mari, text 115% |
| **Cognitiv / neurodivergent** | text 120%, limbaj simplificat, ținte mari |

Opțiuni individuale: mărime text (Normal / Mare / Foarte mare), contrast ridicat,
paletă daltonist, alerte vizuale + vibrație, ghidaj vocal, tastare prioritară,
ținte mari, limbaj simplificat.

## Ce dizabilități pot lucra într-un aeroport

Nu există o listă unică — depinde de țară, de operator și de cerințele de
siguranță ale postului. Exemple reale de roluri și accommodations:

| Dizabilitate | Roluri posibile (exemple) | Accommodations |
|---|---|---|
| **Vedere redusă / orb** | customer service, call center, dispecerat/admin, planificare, IT support, baggage tracing, HR | screen reader, text mărit, contrast, ghidaj vocal, tastatură, trasee tactile |
| **Surd / hipoacuzic** | bagaje, curățenie, catering, rampă (cu semnalizare vizuală), admin, IT, customer service text | alerte vizuale/vibrație, interprete semne, instruiri scrise, radio cu text |
| **Mut / fără voce** | check-in/admin, dispecerat prin text, customer service chat, IT, back-office | comunicație scrisă, TTS pentru interlocutor, fără apeluri vocale obligatorii |
| **Mobilitate redusă** | gate agent, customer service, securitate (post adaptat), administrativ, retail | birouri adaptate, rampe, ținte mari, sarcini fără deplasare |
| **Daltonism** | majoritatea rolurilor operaționale, IT, admin, bagaje | etichete textuale, forme/iconițe, palete sigure |
| **Neurodivergent / cognitiv** | IT, admin, planificare, bagaje, suport clienți | instrucțiuni clare, pauze, mediu predictibil, limbaj simplificat |
| **Boli cronice / fatigabilitate** | roluri de birou, dispecerat, planificare | program flexibil, pauze, muncă hibridă |

Rolurile strict legate de siguranța aeronavelor (tehnicieni de aeronave,
controlori de trafic) au cerințe medicale și de certificare specifice; decizia
se ia individual, cu medicină aeronautică.

## Cum se leagă de flux

- **Reporterul** are voce, meniu 8×8×8 și tastare — nu obligă microfonul.
- **Alertele** pot fi vizuale/vibrație pentru persoanele surde.
- **Textul** și contrastul se aplică global, inclusiv în meniul de incidente.
- **Harta GPS** are coordonate și precizie afișate textual, nu doar vizual.
- **Poza** este opțională și are 5 secunde; nu blochează un raport periculos.
